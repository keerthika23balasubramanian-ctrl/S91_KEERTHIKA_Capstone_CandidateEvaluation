# Candidate Evaluation Platform

## Capstone Project

### Project Topic
Recruitment teams receive large volumes of applications and spend significant time manually screening candidates. A candidate evaluation platform can improve efficiency and reduce hiring effort.

### Project Idea
The **Candidate Evaluation Platform** is a web application designed to help recruitment teams manage and evaluate job applications efficiently. The platform will allow recruiters to view candidate information, compare applications, evaluate candidates using defined criteria, and shortlist suitable candidates.

### Brief Description
The application aims to reduce the time and effort involved in manual candidate screening. Recruiters can manage candidate profiles, review resumes and application details, assign evaluation scores, add feedback, and track shortlisted candidates through a simple and organized interface.

### Main Objectives
- Reduce manual effort in candidate screening.
- Organize candidate information in one platform.
- Provide a structured candidate evaluation process.
- Allow recruiters to score and compare candidates.
- Make shortlisting faster and easier.
- Maintain candidate evaluation records.

### Planned Features
1. Recruiter dashboard
2. Candidate registration/profile management
3. Candidate application list
4. Resume and candidate detail viewing
5. Candidate evaluation and scoring
6. Recruiter comments and feedback
7. Candidate filtering and searching
8. Shortlisting and rejection status
9. Candidate comparison
10. Basic application status tracking
